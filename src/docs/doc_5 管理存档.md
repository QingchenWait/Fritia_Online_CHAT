## 📇 APP 的存档保存在哪里？

- **网页端**：保存在你使用的浏览器内部。必须使用同一个浏览器，访问 [https://chat.fritia.online](https://chat.fritia.online)，才能正确继承存档。
- **Windows**：保存在 `C:\Users\<你电脑的用户名>\AppData\Roaming\fritia-next-chat-electron`位置。直接使用新版 APP 客户端，不会导致存档丢失。
- **Android**：保存在安卓包体内部。因此，更新 APP 版本时，切勿直接卸载旧版本！

## 📇 导入与导出存档

点击**侧边栏** (移动端底栏) 上的 `存档备份` 按钮 (一个刷新样式的 logo)，即可进入导入导出存档页面。

- **存档导出**: 点击 `导出备份`，在系统保存窗口选择 ZIP 保存位置；取消不会产生成功记录。Android / Windows v1.0.1 客户端使用原生选择器；网页浏览器若不支持指定路径，会使用浏览器下载方式，可在浏览器设置中开启下载前询问位置。文件名以 `fritia-chat-archive` 开头。
- **存档导入**: 点击该窗口中的 `点击选择存档 ZIP` 按钮，并在弹出的文件选择器中，选择先前导出的存档，即可实现存档数据恢复。

## 📇 存档云端同步

APP 支持通过 WebDAV 协议，进行存档的定时云端同步。

- Windows/安卓客户端，可以使用 [坚果云](https://help.jianguoyun.com/?p=2064) 实现免费 WebDAV 云端存档同步。
- 浏览器可能需要查找另外的 WebDAV 服务器，或者直接自建 (注意：服务器端需要允许 **CORS** 跨域数据传输)。

以坚果云为例，您需要在 **WebDAV 同步配置** 栏目中，点击 `编辑配置` 按钮，并按照 [坚果云官方教程](https://help.jianguoyun.com/?p=2064) 完成相关配置，并打开启用 WebDAV 自动同步的开关。

**坚果云对 WebDAV 请求频率、文件大小和目录列表有限制，难以实现多端数据实时同步，请主要作为备份使用。** 切换设备前后可各手动同步一次，建议保留独立 ZIP 备份。

## 📇 不同设备的云端同步说明

**v1.0.1** 之后的版本，加入了多端数据合并和冲突数据手动选择功能，在 WebDAV 服务器上，会保存为 `fritia-sync-v2` 子目录 (旧目录内容不会被删除)。如果希望在多设备使用同一份存档，**请将参与同步的设备都升级到 v1.0.1 版本以上**。

新版存档会合并不同设备独立新增的消息，并只上传变化记录；图片等未改变的媒体不重复上传。同一记录被不同设备修改时，会弹出比较窗口，注明快照时间、设备和记录路径，可逐项选择保留值，或稍后处理。自动同步不传播删除，以避免另一台设备尚未同步的记录被误删。

存档页下方“同步恢复副本”可刷新列表并导出合并前的本地 / 云端 ZIP。该副本保存在当前设备，云端另保留历史版本；不要清理浏览器数据或卸载 APP 后才寻找本机恢复点。历史不自动删除，会占用本机和服务器空间。

旧版云存档无需更换同步路径。对于旧清单与实际文件不一致但 JSON 有效的情况，APP 会确认数据读取稳定，先保留原始云端副本，再合并迁移；旧目录保持原样。可以导出恢复列表中的“旧版云端迁移”条目，ZIP 内含 `legacy-source/` 原文件。若提示文件正在变化，请等旧设备同步结束；若 JSON 已损坏或文件缺失，需先从有效备份恢复该文件，APP 不会以空内容覆盖。

新版使用 `fritia-sync-v2` 目录，可首次读取旧版目录，旧目录不会删除；旧客户端看不到 v2 的新记录。若坚果云目录达到列举上限，APP 会停止写入：先导出各设备 ZIP，归档原云端目录，再配置新的同步路径。
